INTERPRETATION
================================================================================

A robust NNRD metric should show:
  1. Significant difference from zero (t-test p < 0.05)
  2. NO significant variation with nuisance parameters (Kruskal-Wallis p >= 0.05)
  3. Homogeneous variance across conditions (Levene p >= 0.05)
  4. Correct sign for the label type (+ve for structure, -ve for feature)
  5. Low coefficient of variation (CV < 0.3)

- A robust metric should show:
  1. Sign invariance: correct direction for all parameter values
  2. Magnitude consistency: low CV across parameter changes
